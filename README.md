# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, projects, education, certifications, and interests as a Computer Science Engineering student.

## ✨ About the Project

This portfolio website is designed to provide an overview of my technical skills, projects, achievements, and professional journey.

It serves as a personal space where recruiters, developers, and others can learn more about my work and experience.

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality

## 📌 Features

* 👩‍💻 Personal introduction
* 🛠️ Technical skills
* 📂 Projects showcase
* 🎓 Education details
* 📜 Certifications
* 📞 Contact information
* 📱 Responsive design

## 🚀 Getting Started

To run this portfolio locally:

### 1. Clone the repository

```bash
git clone https://github.com/priyanshi3735/portfolio_priyanshiDixit.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd portfolio_priyanshiDixit
```

### 3. Run the website

Open the HTML file in your browser.

You can also use **VS Code Live Server** for a better development experience.
